## Brand & Style

This design system establishes a high-precision, ethereal studio environment for audio engineers, creators, and automated podcast production teams. It merges technical discipline with hyper-modern luxury, balancing dark, cosmic space against luminous atmospheric optical phenomena.

### Aesthetic Movement
The design movement is **Luminous Deep-Space Glassmorphism**. It is defined by:
- Multi-chromatic depth: Subdued atmospheric blooms of spectral cyan and electric violet submerged beneath pitch-black layers.
- Optical fidelity: Razor-thin specular reflections, semi-translucent frosted viewports, and light-refracting edge treatments.
- Utilitarian precision: Crisp data visualizations, tight micro-typography, and ergonomic broadcast audio controls.

### Emotional Response
The interface evokes surgical focus, creative elevation, and high-tech command. The space feels silent, tactile, and responsive—resembling an astronomical observatory console transformed into an audio mastering suite.

## Colors

The palette is engineered around pure chromatic contrasts set over an infinite dark plane. 

### Canvas and Background Surfaces
- **Cosmic Obsidian Base:** `#08090f` — Primary viewport canvas.
- **Cosmic Slate Sub-surface:** `#0d111a` — Background panel layer behind frosted viewports.
- **Ambient Chromatic Wells:** Low-opacity radial glows using electric violet (`rgba(176, 38, 255, 0.12)`) and luminous cyan (`rgba(0, 242, 254, 0.08)`) centered beneath key activity zones.

### Glass Substrates
- **Glass Panel Surface:** `rgba(13, 17, 26, 0.65)` to `rgba(20, 26, 38, 0.75)` with optical backdrop-filter blur.
- **Glass Panel Highlight (Top Edge Specular):** Linear gradient from `rgba(255, 255, 255, 0.18)` bleeding down into `rgba(255, 255, 255, 0.04)`.
- **Panel Borders:** `rgba(255, 255, 255, 0.08)` baseline, scaling up to `rgba(0, 242, 254, 0.35)` upon active focus states.

### Host & Telemetry Color Coding
- **Host Alex (Primary Voice / Lead Anchor):** Luminous Cyan (`#00f2fe`), paired with dark cyan container tints (`rgba(0, 242, 254, 0.12)`).
- **Host Sam (Secondary Voice / Co-Host):** Electric Fuchsia/Violet (`#b026ff`), paired with dark fuchsia container tints (`rgba(176, 38, 255, 0.12)`).
- **Audio Master / System Alerts:** Amber Gold (`#ffb703`) for peak warnings; Signal Coral (`#ff3366`) for hard clipping / recording indicators.

## Typography

The typographic hierarchy pairs the structured, geometric attitude of **Space Grotesk** with the neutral, hyper-readable clarity of **Inter**.

- **Space Grotesk** commands brand headlines, high-level structural metrics, dynamic studio track labels, telemetry badges, and timecodes.
- **Inter** manages continuous body text, transcript logs, editing notes, settings values, and dense dialogue scripts, preventing visual fatigue across extended editing workflows.
- Dynamic telemetry, frame counts, and decibel indicators utilize `telemetry-data` with tabular numerical alignment to prevent jitter during real-time playback.

## Layout & Spacing

The layout is built around a flexible 12-column digital audio workstation (DAW) grid, adjusting gracefully between dense track mastering screens and streamlined snippet generation panels.

### Grid & Breakpoints
- **Desktop (1280px and above):** 12-column fluid grid. Gutters: `1.25rem`. Margins: `2rem`. Supports three-column studio views: Left (Session Assets / Script Tracks), Center (Waveform Timeline / Playback Stage), Right (Audio Filters / AI Snippet Synthesizer).
- **Tablet (768px – 1279px):** 8-column layout. Gutters: `1rem`. Margins: `1.5rem`. Collapses the Inspector and Clip Library into flyout glass drawers.
- **Mobile (< 768px):** 4-column stack. Gutters: `0.75rem`. Margins: `1rem`. Prioritizes real-time waveform scrubbers, rapid snippet trims, and immediate share triggers.

### Spacing Rhythm
Maintain an internal 4px / 8px scale for compact controls. Padding within glass cards must remain generous (`space-md` to `space-lg`) to prevent content from bleeding into luminous edge borders and backdrop highlights.

## Elevation & Depth

Depth is established through multi-pass transmission, specular refraction, and ambient backlighting rather than conventional heavy drop shadows.

### Glassmorphism Stack Architecture
1. **Backdrop Layer (Elevation 0):** Obsidian `#08090f` background with dynamic radial gradients generating atmospheric color pools.
2. **Standard Studio Panel (Elevation 1):** 
   - Surface: `background: rgba(13, 17, 26, 0.65)`
   - Filter: `backdrop-filter: blur(20px) saturate(180%)`
   - Border: `1px solid rgba(255, 255, 255, 0.08)`
   - Edge Glow: Top specular border line generated via `linear-gradient(90deg, rgba(255,255,255,0.12), rgba(255,255,255,0.02))`
   - Shadow: `0 8px 32px 0 rgba(0, 0, 0, 0.45)`
3. **Floating Floating Tools & Popovers (Elevation 2):**
   - Surface: `background: rgba(20, 26, 38, 0.8)`
   - Filter: `backdrop-filter: blur(28px) saturate(200%)`
   - Border: `1px solid rgba(255, 255, 255, 0.15)`
   - Shadow: `0 16px 48px rgba(0, 0, 0, 0.6), 0 0 20px rgba(0, 242, 254, 0.08)`
4. **Active Selection & Modals (Elevation 3):**
   - Direct luminous accent shadows corresponding to the active role: Alex cyan (`rgba(0, 242, 254, 0.2)`) or Sam violet (`rgba(176, 38, 255, 0.2)`).

## Shapes

The interface balances ergonomic fluid shapes with structured modular frames:
- **Panels & Containers:** `rounded-lg` (1rem / 16px) establishes clean, architectural frames for sound stages, meters, and clip trays.
- **Interactive Controls (Buttons, Inputs, Knobs, Sliders):** `rounded` (0.5rem / 8px) ensures accurate target recognition and precise tactile response.
- **Status Pills & Role Badges:** Fully rounded capsule/pill styles (`rounded-full`) denote speaker tags, telemetry statuses, and dynamic snippet flags.

## Components

### Buttons
- **Primary Studio Action:** Gradient fill from cyan `#00f2fe` to secondary `#4facfe`, overlaid with dark slate text (`#08090f`, font-weight 700). High hover radiance: `box-shadow: 0 0 24px rgba(0, 242, 254, 0.45)`.
- **Glass Action (Secondary):** Surface `rgba(255, 255, 255, 0.05)`, border `1px solid rgba(255, 255, 255, 0.12)`, text `#ffffff`. On hover: surface `rgba(255, 255, 255, 0.1)`, border `rgba(255, 255, 255, 0.25)`.
- **Destructive / Cut Action:** Surface `rgba(255, 51, 102, 0.1)`, border `rgba(255, 51, 102, 0.3)`, text `#ff3366`.

### Chips & Speaker Badges
- **Pill Shape:** Height of 24px, text set in `label-sm`.
- **Host Alex Tag:** Background `rgba(0, 242, 254, 0.12)`, border `rgba(0, 242, 254, 0.35)`, text `#00f2fe`. Includes a 6px luminous pulsing cyan dot for speaking status.
- **Host Sam Tag:** Background `rgba(176, 38, 255, 0.12)`, border `rgba(176, 38, 255, 0.35)`, text `#d980ff`. Includes an electric purple status indicator.

### Input Fields & Search Bars
- Glass trench design: `background: rgba(8, 9, 15, 0.75)`, recessed border `1px solid rgba(255, 255, 255, 0.08)`.
- Focus state: Subtle inner cyan glow (`box-shadow: inset 0 0 12px rgba(0, 242, 254, 0.15)`) and edge border shifting to `rgba(0, 242, 254, 0.5)`. Typography in `body-md` with white text.

### Audio Waveform Track Cards
- Glass cards with 20px blur, `1px solid rgba(255, 255, 255, 0.08)`.
- Audio channel tracks highlighted by host assignment: Alex clips display cyan waveform spikes over darkened indigo, Sam clips display violet spikes.
- Playhead marker: 2px sharp solid white vertical line with a glowing drop shadow (`0 0 10px #00f2fe`).

### Telemetry Readouts & Meters
- Monospaced numeric displays (`telemetry-data`) detailing decibels, sample rates (e.g., `48.0 kHz / 24-bit`), and snipped video dimensions.
- VU meters: Segmented LED bars in glass grooves, transitioning from bright cyan through deep violet to alert coral at 0 dB.
